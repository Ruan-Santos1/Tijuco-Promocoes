## 📌 Sobre o projeto

O **Tijuco Promoções** é uma aplicação web desenvolvida com o objetivo de conectar consumidores e comerciantes de Ituiutaba, Minas Gerais.

A plataforma permite que lojistas divulguem seus produtos e ofertas, enquanto os consumidores podem descobrir oportunidades de compra no comércio local.

O projeto busca fortalecer os negócios da região, facilitar o acesso às promoções e oferecer uma experiência simples, intuitiva e acessível.

## ✨ Funcionalidades

- 📢 Divulgação de promoções e ofertas.
- 🏪 Cadastro de lojistas.
- 🔐 Autenticação de usuários.
- 🖼️ Cadastro de promoções com imagens.
- 🔎 Busca e filtragem de ofertas por categoria.
- ❤️ Sistema de favoritos.
- 📱 Interface pensada para dispositivos móveis.
- 🗄️ Integração com Supabase para armazenamento e gerenciamento dos dados.

> As funcionalidades podem evoluir conforme o desenvolvimento do projeto.

## ⚙️ Como executar o projeto

### 1. Pré-requisitos

Para executar o projeto localmente, você precisará de:

- [Visual Studio Code](https://code.visualstudio.com/)
- Navegador atualizado
- Projeto configurado no Supabase
- Extensão Live Server no VS Code (opcional)

### 2. Clonar o repositório

```bash
git clone https://github.com/Ruan-Santos1/Tijuco-Promocoes.git
```

Entre na pasta do projeto:

```bash
cd Tijuco-Promocoes
```

### 3. Configurar o Supabase

O projeto utiliza o Supabase para gerenciar os dados e a autenticação.

Para configurar:

1. Crie um projeto no [Supabase](https://supabase.com/).
2. Configure as tabelas necessárias no banco de dados.
3. Configure o acesso ao Supabase no arquivo de configuração do projeto.
4. Verifique as políticas de segurança (RLS) das tabelas.
5. Execute o projeto utilizando o Live Server.

**Importante:** nunca publique chaves secretas ou credenciais administrativas no frontend ou no GitHub.

### 4. Executar localmente

Abra a pasta do projeto no Visual Studio Code.

Clique com o botão direito no arquivo `index.html` e selecione:

**Open with Live Server**

O projeto será aberto no navegador.
