## 📌 Sobre o projeto

O **Tijuco Promoções** é uma aplicação web desenvolvida para conectar consumidores e comerciantes de Ituiutaba, Minas Gerais.

A plataforma permite que lojistas divulguem seus produtos e ofertas, enquanto os consumidores podem encontrar oportunidades de compra no comércio local.

O objetivo é fortalecer os negócios da região, facilitar o acesso às promoções e oferecer uma experiência simples, intuitiva e acessível.

## ✨ Funcionalidades

- 📢 Divulgação de promoções e ofertas.
- 🏪 Cadastro de lojistas.
- 🔐 Autenticação de usuários.
- 🖼️ Cadastro de promoções com imagens.
- 🔎 Busca e filtragem por categoria.
- ❤️ Sistema de favoritos.
- 📱 Interface adaptada para dispositivos móveis.
- 🗄️ Integração com Supabase.

## 🚀 Como executar o projeto

### Pré-requisitos

- Visual Studio Code
- Navegador atualizado
- Projeto configurado no Supabase
- Extensão Live Server (opcional)

### 1. Clone o repositório

```bash
git clone https://github.com/Ruan-Santos1/Tijuco-Promocoes.git
```

### 2. Abra a pasta no VS Code

Entre na pasta do projeto:

```bash
cd Tijuco-Promocoes
```

### 3. Configure o Supabase

O projeto utiliza o Supabase para autenticação e armazenamento de dados.

Para executar corretamente:

1. Crie um projeto no Supabase.
2. Configure as tabelas necessárias.
3. Configure a conexão no arquivo `supabase.js`.
4. Verifique as políticas de segurança (RLS).
5. Abra o `index.html` utilizando o Live Server.

> Nunca publique chaves secretas ou credenciais administrativas no frontend ou no GitHub.
